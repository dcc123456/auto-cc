# 一周变现立项书（草案）· 可售求职服务包

> 立项人：中书省｜交办：太子（2026-11-22）｜性质：**业务立项草案，不是代码子计划**
> 若要转成正式子计划，须由尚书省在 `docs/00-master-plan.md` §4 登记后开工；本文不改任何 spec、不动代码。
> 边界（不可谈判）：收款账户、实名认证、平台开店**一律由皇上本人办理**；臣等只做产品、文案与工具，
> 不代收钱、不代注册账号、不索要密码。

## 0. 一句话

把项目已有的「简历知识库 + 按 JD 定制 + PDF 生成」包成三个明码标价的人工服务包，
用最低价换头几单与口碑，一周内验证「有没有人愿意为这个付费」——**先验证成交，再谈规模化**。

## 1. 卖什么（三个 SKU，先只卖这三个）

| SKU | 交付物 | 交付工时 | 早鸟价 | 标准价 |
| --- | --- | --- | --- | --- |
| S1 简历精修 | 现状诊断 → 逐条改写 → 一页 PDF（中英任一） | 1.5–2 h | **49 元**（限前 5 单） | 99 元 |
| S2 按岗位定制 | 指定 JD 一份 → 定制版简历 + 匹配点解释 + 一句打招呼语 | 2–3 h | **99 元** | 199 元 |
| S3 面试陪练 | 按目标 JD 出 8–10 题 → 30/60 分钟真人陪练 → 逐题复盘要点 | 1 h | **59 元 / 30 分钟** | 149 元 / 60 分钟 |

成本结构：**边际成本几乎为零**（工具本地跑，无 API 大额消耗），真正成本是皇上本人的 1–3 小时。
所以定价下限由「时薪」决定：一单 99 元 / 2 小时 ≈ 50 元·小时，低于这个数就不值得接。

## 2. 卖给谁（按出单概率排序，先熟人后平台）

1. **熟人 / 校友 / 前同事群**——信任成本最低，当天可能出单，不需要任何账号与开店。
2. **小红书 / 闲鱼**——有搜索流量，但需皇上本人的账号与实名；发「求职季改简历」图文，导私信成交。
3. **校招群、技术社区**——发一条「秋招简历义诊，前 3 单免费诊断」换案例。

不做：投广告、买流量、刷单刷评、买粉。零预算起步，靠真人服务换第一批评价。

## 3. 定价依据（市面带，非拍脑袋）

| 参照 | 市面读数 | 来源 |
| --- | --- | --- |
| 简历代写/修改 | 5 元至数百元不等；闲鱼常见报价 **299 元** | [百度问一问·代写简历价格](https://wen.baidu.com/)、豆瓣小组闲鱼报价帖 |
| 简历代写（淘宝店） | 模板代制作 + 代写 + 排版，几十至上百元 | [淘宝「简历代制作代写」商品页](https://www.taobao.com/) |
| 面试陪练（个人/独立） | **60–250 元/小时**，资深可达 200–250 | 360 检索聚合·公考陪练口径 |
| 面试辅导（机构一对一） | **500–600 元/小时** | 教育机构公开报价 |
| 溢价乱象 | 有「2000 元聊一小时」的报道 | [中国网·付费面试辅导乱象](https://henan.china.com.cn/) |

**结论**：我们零品牌、零评价、无交付历史，只能取**市价下沿**做首单（49/99/59），
D7 之后再按成交率决定是否上探到 99/199/149。**不打折到 9.9**——那会把「专业服务」卖成「白菜代写」，
来的是最难伺候、最不转介绍的单。

另：市面还有 3980 元「跳过网申直通面试」一类，**属于明确的红线，绝不碰**（见 §6）。

## 4. 一周七天：每天一件可验收的事

| 日 | 交付 | 验收（做到了就是做到了） |
| --- | --- | --- |
| D1 | 三档服务说明 + 报价单 + 一段私信话术（≤120 字） | 一页图文能直接发出去，不用再改 |
| D2 | 交付 SOP：接单问什么、改哪几处、怎么交 PDF、怎么要反馈 | 用自己/家人的真简历走通一遍全流程 |
| D3 | 两个「前后对比」样例（打码）+ 挂单/发帖文案 | 两张对比图 + 三段文案就绪 |
| D4 | 第一波触达：熟人群发一条，小红书/闲鱼挂一单 | 发出去了，且记录触达人数 |
| D5 | 首单交付（有单则做，无单则免费义诊 2 单换案例） | 交付记录 + 客户一句原话 |
| D6 | 复盘：咨询→付费转化率、卡在哪一步 | 一页读数，不写感想写数字 |
| D7 | 决策：调价 / 换渠道 / 停 | 写明「继续/改/停」与依据 |

**一周现实营收区间：0–300 元**（3 单 × 49–99 元）。这个数字要在立项时就说明白，不粉饰。

## 5. 皇上每天要花的力气

约 **30–60 分钟**：发一条群/朋友圈、回私信、做一单交付。收款用皇上自己的微信/支付宝，
臣等只提供**报价单、话术、SOP、样例与质检清单**。

## 6. 红线（触一条即停止本周立项）

1. 不代收款、不代实名、不索要任何账号密码。
2. 不承诺「保过/保面试/保 offer/内推名额」——市面那类 3980 元产品就是靠这句话骗钱的。
3. 不虚构、不美化客户经历；简历事实锁定，改的是表达与结构，不是编造履历。
4. 不刷单、不刷评、不买流量、不做返现拉人。
5. 不接「先干活后付款」的大单；不接要求提供他人简历/身份信息的单。

## 7. 建议分工（由尚书省派工，非本人直接调动）

- **礼部**：服务说明、挂单文案、前后对比样例的排版与措辞。
- **户部**：报价单与成本台账（每单工时 vs 收入），D6 的转化率读数。
- **兵部**：把「简历诊断 → 按 JD 定制 → 导出 PDF」压成一条顺手的操作路径，减少每单手工步骤。
- **刑部**：核 §6 话术与文案，特别是「不承诺 offer」这一条。
- **门下省**：审本立项书的边界与验收口径。
