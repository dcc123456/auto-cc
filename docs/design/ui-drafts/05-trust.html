  1. 信任层自成一区。今天这些内容散在 PrivacyNotice、ConsentCard、AgentPolicyPanel、UsagePanel、AuditSection 五处；用户想知道"它到底能替我做什么"时必须一跳一跳找。
  2. 调试工具与信任设置分开。工程台只读、不外发，因此不混进这一栏，避免"设置页很危险"的错觉。
  3. 签字落在纸上。暖纸 + 手写字 + 骑缝朱砂章，与对话屏的盖印同一套材质语言：外发是同一种"按下去就有后果"的动作，视觉上也该是同一类。
  4. 风控那条写成"不可关闭"。§8.3 的红线要在界面上表现为没有开关，而不是一个默认勾选的复选框。
  5. 白名单每行都带效果芯片。加白之前就知道这是只读还是外发；外发行默认半透明，需显式操作。
  6. 写明"落 SQLite 而非配置键"。这条约束（配置层重启即失）直接印在页脚，防止后来者把它改回配置项。
  7. 闸门拒绝必须返回原因码并在计划卡上停下——把这条行为写进界面文案，UI 与实现对得上。
  8. 账本与审计合并成一张表，新增"谁批的"列。这是全套设计里最实用的一列：出事时先看这列。
  9. 危险操作留在信任区并标朱砂，二次确认；不在对话里用一个"删掉所有数据"的自然语言指令就能触发。
