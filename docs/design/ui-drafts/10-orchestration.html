  • ①标题栏副标题就是面包屑的最后一跳：「编排中（草稿未校验）」用 amber，运行中转 celadon，停靠等印转 seal。人任何时候抬头都知道自己在哪个相位。
  • ②「编排」与「运行」是同一视图的两个相位，不是两个页面。相位切换在右上角「退出编排 →」；进入编排的唯一路径是计划卡上的「编排」，因此不存在"编辑完不知道去哪跑"。
  • ③「运行」按钮的禁用态是这张稿的钥匙：草稿脏（SCRIPT_DIRTY）时按钮转灰 + 旁边挂原因码，点它不弹窗，而是把焦点交给底部问题条的第一条错误并高亮对应节点。原因码必须出现在按钮右边，不能只写在 tooltip 里。
  • ④算子面板按效果三色分组（只读 / 本机写入 / 外发），不是按技术分类。搜索按能力词命中（"抓取"能搜到 page.snapshot）。
  • ⑤拖拽的三态：默认（左手柄 ⠿ 半透明）→ 悬停（描边提亮，无位移）→ 拖动中（朱砂虚线 + 原槽位留 40% 透明残影）。画布上的落点用青瓷虚线框（⑧）表达，不用整块高亮。
  • ⑥外发算子拖入即挂停靠，检查器里那一格默认勾上且灰化说明"取消需先撤回授权"。这是 §8.3 与 entitlement.gate 的界面表达：不做"批量免确认"的入口。
  • ⑦连线中：起点端口转青瓷实心 + 光晕，临时线用虚线跟随，只允许连到类型兼容的端口（不兼容的端口保持灰，松手不落线并给一次 toast 说明类型不匹配）。
  • ⑧松手插入：新节点落在 drop 框位置，自动接上被穿过的那条边（插队而非并列），插入后立刻进选中态并打开检查器。
  • ⑨选中态 = 白描边 + 四角把手 + 检查器同步。单选才有检查器；多选（框选 / ⇧点）时检查器换成"批量"面板：对齐、批量禁用、批量删除（走两步就地）。
  • ⑩停靠节点用朱砂虚线边框 + 停靠标签。运行相位下它会呼吸式脉冲（sealPulse），停在它上面时底栏出现「等待盖印 · 已等 02:14」。
  • ⑪输入映射是编排台里最容易做错的一格：每行右侧的「改」走行内编辑（形态②），下拉里只列类型兼容且拓扑在上游的输出；选不到就写常量。未映射不报错、只警告，运行到那一步才真失败。
  • ⑫「失败时」三选是每节点必填的显式策略，没有"默认重试"。外发节点强制"停整条"，选项置灰并给原因码 OUTBOUND_MUST_STOP——防止静默重发造成骚扰。
  • ⑬底部问题条与底栏是两层不同的东西：问题条讲"这条草稿现在能不能跑"，底栏讲"这台机器现在什么状态"。诊断面板（⌘J）仍然比主视图低一档，不在此屏内出现。
