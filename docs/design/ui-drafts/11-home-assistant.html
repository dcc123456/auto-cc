11-E 状态与边界 胶囊四态 / 最小化条 / 空态（替换版面）/ 读不到（不画 0）
胶囊 · 空闲（唯一入口）
左：收起。右：展开（加一圈 inset 青瓷提醒"它开着"）。常驻顶栏最右，七屏 / 站点全屏 / 窄窗都在同一点。 h-8 · px-2.5 · rounded-full · solid
胶囊 · 进行中 / 需要你 / 被拦
三种都占同一个角标位、不改文案也不跳宽：进行中 = 青瓷点（静态，不做脉冲）；需要你 = 琥珀计数（待确认计划 + 逐条批准 + 执行器待办）；被拦 = 朱砂点（风控/验证码/闸门拒绝）。 普通未读不亮 —— 不做消息中心

11-F 规格、取舍与待验证

几何与层级

胶囊 顶栏最右，h-8 / px-2.5 / rounded-full；<1120px 只留图标（NarrowLabel）
面板 父级 = main；absolute inset-y-3 right-3；w-[min(420px,calc(100%-1.5rem))]
最小化 同锚点、同宽、h-12
层级 面板 z-20；toast z-30；抽屉/弹窗 40/50（既有）；不进焦点环（非模态）
间距 块间 16；块内 p-4；行内 8；页内 20
圆角 面板/卡 12；控件 7；标签 4；胶囊 999

字体与颜色

档位 招呼 20 / 块标题 12.5 / 数字 28 / 格标签 11 / 口径 10.5
数字 font-mono + tabular-nums，不跳宽；单位用 11px 正文字
正文 11–12px slate-400（墨案 6.38 / 毡案 6.55，过 4.5）
数字 slate-50（16.23）
状态色 青瓷=进行中/现在做；青玉=已完成；琥珀=等你表态；朱砂=被拦/风险
禁用 seal 不上普通按钮，也不给"助手"这个入口本身

键盘与读屏

  • ⌘/Ctrl+J 呼出/收起；Esc 收起并回焦胶囊
  • 呼出后焦点落输入卡；面板不锁 Tab，背景可继续用
  • role="dialog" aria-modal="false" aria-label="助手"；胶囊 aria-expanded/controls
  • 状态点 aria-live="polite"，只播"需要你/被拦"，不播流式文本
  • 开合仅 animate-rise 一次 + motion-reduce:animate-none；无循环动画

取舍与不做

  • 不做右下 FAB：原生网页视图会吃掉它，站点全屏时左栏连 DOM 都没有
  • 不做拖拽/缩放：第二份几何事实，且与站点分栏把手抢手势
  • 不做遮罩/模态：背景要能继续用
  • 不做助手专属卡片：复用 ChatPanel 的计划卡与审批卡
  • 不做转化率：小样本比率会误导
  • 不做固定宫格：入口按状态排序，一屏最多 4 条
