SCREEN 07 控件状态机 每一类可点的东西长什么样、鼠标按下去变成什么样、点完之后变成什么样——一张表说死，实现层不再自行发明
五态总则
① 默认：底色 ink-750、描边 line-strong、无阴影。
② 悬停：底色提一档到 ink-700，描边转实——不做位移（位移只属于"按下"，两者混用会让人以为已经点了）。
③ 按下：translateY(1px) + 底色回落到 ink-800 + 阴影清零，手上有"沉下去"的一格。
④ 进行中：文案换成进行时 + 转针，宽度锁死不跳版；此时整颗视为已禁用，重复点击无效。
⑤ 结果：成功描青（jade）并把文案换成完成态，2 秒后自动回落；失败描朱（seal）且不自动回落，必须人处理。
另有一条硬规矩：不可点的元素绝不长出 hover（效果芯片、标签、读数都不响应鼠标），"看起来能点"在这套界面里是缺陷。

三 · 点击之后发生什么：只有这六种形态
这是"点修改是弹窗还是直接改"这类问题的总答案。全 app 的每一个控件都必须落进下面六格之一，不允许出现第七种（比如"点了没反应，等 3 秒后页面自己变了"）。逐控件归属见 08 稿。
形态 ①就地回执
已保存
用于：保存、复制、加入白名单、导出。按钮自己变青换文案，2 秒回落，页面不滚动、不弹层。
形态 ②行内编辑（不弹窗）
项目经历⏎ 保存 · Esc 取消
用于：改名类（计划重命名、区块标题、话术微调）。原地沉进 ink-950 的"井"里 + 青瓷描边；⏎ 存、Esc 退，Esc 时若内容有变，长按 1 秒才真丢弃。超过 3 行的正文不用行内，见 09 稿。
形态 ③右栏替换
右栏 → 快照回放主区不动
用于：看证据、节点详情、抓取原文、PDF 预览。只读的东西一律不弹窗——它不该打断你正在做的事。右栏顶部出现"← 返回内核页面"一颗。

四 · 键盘等价与焦点次序
每一颗鼠标动作都要有键盘等价，否则自动化测试无法覆盖（§7.1 的 V 类靠 harness 点，也靠这条）。
⌘K
全局命令面板：输入区名 / 岗位标题 / 工具 id 直接跳，等价于点左栏。
⏎ / Esc
行内编辑保存 / 取消；弹窗里 ⏎ 只作用于安全那颗按钮，盖印与删除永远不接 ⏎（防回车通过）。
⇧
输入框换行不发送（发送口只认 ⏎）。
⌘Z / ⇧⌘Z
撤销 / 重做，作用域跟着焦点走：焦点在简历编辑器就只撤简历，不会把话术改动一起撤掉。
Tab
次序固定为 左栏 → 主区 → 右栏 → 底栏；遮罩弹窗打开时焦点锁在弹窗内，关掉后回到唤起它的那颗控件。
Space
画布节点获得焦点后按空格 = 选中并替换右栏（等价于单击），不会触发运行。
  • hover 与 active 不共用视觉：位移只属于按下。这条来自实测习惯——用户分不清"悬停即生效"和"要点一下"。1
  • 禁用必须带原因：只降透明度而不写原因的按钮视为缺陷；原因写进 title 与旁边的 hint，且用原因码（ENTITLEMENT_EXHAUSTED）与 06 稿对齐。2
  • 加载不跳版：转针态锁最小宽度，文案换进行时动词（保存中 / 盖章中 / 校验中），完成后换结果态。3
  • 结果态的回落时间统一 2 秒，失败态永不自动回落；这套时间是全 app 常量，不在组件里各写各的。4
  • 不可逆动作用原地两次点击，不用弹窗；唯一例外是"清空本机全部数据"与首次风险签字，它们要打字/要读全文。5
  • 只读的东西永远不打断：证据、原文、回放、预览都往右栏放，弹窗只留给"会丢数据或会发出去"两类。6
  • 跨区跳转必须带上下文并长出可回退面包屑，否则用户不知道自己是"新开了一个页面"还是"换了个筛选"。7
  • 每颗按钮都要有键盘等价，且盖印 / 删除这类绝不绑定 ⏎。8
