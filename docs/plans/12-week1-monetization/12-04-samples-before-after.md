## 0. 使用须知（发给客户前先看）

1. **人物全部虚构**：姓名写「张同学 / 李同学」，学校写「某双非本科 / 某虚构学院」，公司写「某虚构科技 / 某虚构商贸」。
   任何真实姓名、学校、公司、电话、邮箱、平台截图都不得出现在样例里，也不得出现真实 JD 截图。
2. **改后不添经历**：所有数字都只能来自客户自己口述或原稿已有的事实。样例里凡是新增的量化，
   都在「客户补充」一栏写明来源。**客户说不出来的数，就写"未量化"，不许编。**
3. **改的是表达**：动词开头、结果前置、关键词对齐 JD、把职责改成「做了什么 + 结果如何」。
   结构可以重排、可以删冗余、可以改措辞；事实不能动。

## 样例一（S1 简历精修）：张同学 · 某双非本科 · 目标岗位「电商运营助理」

### 1.1 改前（客户原稿，典型问题都在）

```
教育背景：某双非本科 市场营销专业 2022-2026
实习经历：某虚构科技 运营实习生 2025.07-2025.09
- 负责店铺日常运营工作，协助上级完成各项任务
- 参与活动策划，配合团队完成活动
- 负责数据整理，制作表格
- 完成领导交办的其他工作
校园经历：学生会干事，参加过一些活动
技能：熟练使用办公软件
```

**问题清单（逐条可指）**

| # | 毛病 | 具体位置 |
| --- | --- | --- |
| 1 | 流水账、无结果 | 四条实习职责全是"负责/参与/配合/完成"，看不出做成什么 |
| 2 | 无量化 | 店铺几个？活动几场？表格多少行？一个数都没有 |
| 3 | 关键词缺失 | 目标岗是电商运营，稿子里没有「GMV / 转化率 / 投产比 / 选品 / 活动复盘」任何一词 |
| 4 | 被动、空话 | 「协助上级完成各项任务」「领导交办的其他工作」= 零信息 |
| 5 | 校园经历形同虚设 | 「参加过一些活动」，读者无法判断能力 |

### 1.2 客户补充（服务时逐条问出来的事实，**这是改写的唯一依据**）

> 我方问：「你管的店铺有几个？活动办了几场？表格里大概多少条数据？学生会具体做了什么？」
> 客户答：「三个店的后台我都管；双十一那场活动我跟了；订单表大概三千多条；学生会我是干事，组织过两场迎新。」

| 补充事实 | 来源 |
| --- | --- |
| 负责 3 个店铺后台 | 客户口述 |
| 参与 1 场大促（双十一）活动执行 | 客户口述 |
| 活动期没有出现错价投诉 | 客户口述 |
| 整理约 3000 条订单数据 | 客户口述 |
| 日均订单量：3000 条 ÷ 90 天 ≈ 33 单/日 | **由上一行折算**，非客户原话；写入简历前须客户确认 |
| 组织 2 场迎新活动 | 客户口述 |
| 单场迎新到场约 200 人 | 客户估数，已确认（估数须标注「约」） |

### 1.3 改后（只用了 1.2 的事实）

```
教育背景
某双非本科｜市场营销｜2022.09–2026.06

实习经历
某虚构科技｜电商运营实习生｜2025.07–2025.09
· 独立维护 3 个店铺后台，负责商品上下架、库存与订单异常处理，日均处理订单约 30 单
· 参与双十一大促执行：按活动排期完成会场商品配置与价格校对，活动期零错价投诉
· 用 Excel 整理约 3000 条订单数据，按 SKU 汇总销量与退款情况，输出一版周报供主管排品参考

校园经历
某双非本科学生会｜干事｜2023.09–2024.06
· 组织 2 场迎新活动，负责场地与物资对接，单场参与学生约 200 人

技能
Excel（数据透视表、VLOOKUP）｜办公软件｜基础图文排版
```

### 1.4 逐条对照（哪一句改了、怎么改、依据什么）

| 改前 | 改后 | 改法 | 依据 |
| --- | --- | --- | --- |
| 负责店铺日常运营工作，协助上级完成各项任务 | 独立维护 3 个店铺后台，负责商品上下架、库存与订单异常处理 | 空话→具体动作；补店铺数 | 客户口述「三个店的后台我都管」 |

| 学生会干事，参加过一些活动 | 组织 2 场迎新活动，负责场地与物资对接，单场约 200 人 | 补场次、补角色、补规模 | 客户口述「组织过两场迎新」；人数为客户估数，已确认 |

**时薪折算**：本单 1.5 小时完成，早鸟价 49 元 ≈ 33 元/小时——属引流单，D7 后应按 99 元档走。

## 样例二（S2 按岗位定制）：李同学 · 某虚构学院 · 目标 JD「运营专员」

### 2.1 虚构 JD（示例，非真实平台截图）

```
某虚构电商公司｜运营专员
职责：
1. 负责类目商品的日常运营与活动落地
2. 通过数据分析定位问题，输出优化建议
3. 跨部门协同（采购、客服、设计）推进项目
4. 参与选品与价格策略制定
要求：
1. 本科及以上，1 年以内经验可投
2. 熟练使用 Excel，会 SQL 者优先
3. 有活动执行经验，能承受大促节奏
```

### 2.2 改前（客户原通用版，投了 30 家没回音）

```
实习经历：某虚构商贸 行政助理 2025.03-2025.08
- 负责文件整理与归档
- 协助部门处理日常事务
- 完成上级安排的工作
校园经历：社团成员
```

**与 JD 的差距（三条硬伤）**：① 完全没有「数据/分析」；② 完全没有「跨部门/项目推进」；
③ 岗位名是「行政助理」，与「运营专员」不搭，读者第一眼就筛掉。

### 2.3 客户补充（改写依据）

| 补充事实 | 来源 |
| --- | --- |
| 每月整理各门店销售报表，做过数据汇总 | 客户口述 |
| 报表按品类 × 门店交叉对比，识别出 3 个下滑品类 | 客户口述（「3 个」为客户估数，已确认；写入须带「约」） |
| 对接过采购与客服两边，催过缺货与退换 | 客户口述 |
| 跨部门事项每周约 10 条 | 客户估数，已确认（写入须带「余」或「约」） |
| 用过 Excel 透视表；**没写过 SQL** | 客户口述（明确没有） |
| 协助过一次门店促销活动的物料准备 | 客户口述 |
| 该次促销覆盖 2 家门店 | 客户口述 |

### 2.4 改后（对齐 JD 的定制版）

```
实习经历
某虚构商贸｜运营支持实习生（原岗：行政助理）｜2025.03–2025.08
· 每月汇总各门店销售报表，用 Excel 透视表按品类与门店交叉对比，标出销量下滑的 3 个品类提交主管
· 作为采购与客服之间的对接人，跟进缺货补货与退换处理，平均每周处理 10 余条跨部门事项
· 协助门店促销活动的物料准备与到场核对，覆盖 2 家门店

匹配说明（随简历一并交付，不进简历正文）
· JD「数据分析定位问题」← 每月销售报表 + 品类下滑定位
· JD「跨部门协同」← 采购/客服双向对接，周均 10 余条
· JD「活动落地」← 门店促销物料与到场核对
· JD「会 SQL 优先」← **不具备，不虚构**；建议面试时以 Excel 透视表能力作答
```

**招呼语（S2 交付物之一，可直接发）**

> 您好，看到贵司运营专员岗要求里提到"数据分析定位问题"，我上一份实习每月做各门店销售报表、
> 用透视表定位过下滑品类并提交主管，和这条比较对得上。简历已按岗位改过一版，方便的话想请您看两眼。

### 2.5 逐条对照

| 改前 | 改后 | 改法 | 依据 |
| --- | --- | --- | --- |
| 负责文件整理与归档 | （删除） | 与 JD 无关，删 | JD 无此要求 |
| 协助部门处理日常事务 | 每月汇总各门店销售报表，用透视表按品类×门店交叉对比，标出下滑的 3 个品类 | 空话→JD 第一条要求的能力 | 客户口述报表与工具；「3 个品类」为客户估数，已确认 |
