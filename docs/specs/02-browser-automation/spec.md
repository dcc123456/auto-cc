# 计划二 · 集成浏览器自动化（spec 验收清单）

方式：**V** = 可视验收（agent 用 CDP harness 打开 app、截图、读 DOM 断言，必须留证据文件）；
**C** = 命令/脚本可机检；**U** = 单元测试。状态：`[ ]` 未验 / `[x]` 通过 / `[!]` 受阻（必须写原因）。

验收纪律依 `AGENTS.md` §7：V 项无截图不得置 `[x]`；测试不得访问真实招聘平台；
每个子计划收口跑 `typecheck / lint / format:check / test` 并逐项更新本表。

> **条目统计**：79 条（2.1×12 / 2.2×13 / 2.3×11 / 2.4×10 / 2.5×11 / 2.6×8 / 2.7×7 / 2.8×7）。
>
> **前置门禁**：P2 开始前，P1 的 1.2 / 1.3 / 1.4 / 1.8 / 1.9 / 1.10 必须已 `[x]`。
> 若 1.8（登录态分区）或 1.9（额度闸门）未过，2.1 / 2.5 / 2.6 直接判 BLOCKED，不得用临时实现绕过。
