### 3.2 验收记录（2026-10-01，本机 Windows）

**本片交付的是「模板 = 纯函数 + 注册表 SPI」这一能力**，落在 `packages/resume-doc`（§4.3：属于既有包，不新建）。测试在 `template.test.ts`（21 例），四道根门全绿（typecheck / lint / format:check / test）。

U/C 可现在兑现的六条：

- **3.2-01**：`resumeTemplate.render(doc, id, locale)` 输出确定性 HTML；同一 doc+模板+语言两次字节一致（不读时钟 / 不读随机），产物含姓名与字段值。
- **3.2-03**：`list()/get()/render()` 三个方法构成 SPI；内置 ≥3 套（classic/modern/minimal）；`get(未知)` 返回 null、`render(未知)` 抛可读错并列出可用 id；测试**运行期 `register()` 一套新模板**后立即出现在 list、render 可用、重复 id 被拒——`list/get/render` 源码一字未改，直接兑现「新增模板不改核心」。
- **3.2-04**：核心槽位（经历/项目/校园的公司+职位、教育的学校）缺失时抛 `TemplateBindingError`，带 `sectionKind` + `fieldKey` + 本地化区块名；三套模板共用同一 `toEntryView`，故同一处绑定缺陷在三套里都可定位（各测一例）。可选字段（电话）缺失只跳过不抛。
- **3.2-05**：扫描 `internal/templates.ts` 源码，断言无 `.slice(` / `.substring(` / `Math.` / `new Date` / `toFixed(` / `parseInt` / `parseFloat` 等业务加工；模板只做「取数据视图 → 拼 class」。
- **3.2-07**：产物 `class="…"` 齐、无 `<style>`、无 `style="`；模板/基元源码不 import 任何 `.css`（1.2-13 口径的生成轨版本）。
- **3.2-10**：每套模板 `origin` 字段标 `clean-room-rewrite`，文件头写明「未从 ai-resume 拷贝 HTML/代码，仅沿用『模板=纯函数』形态」。因**无任何 ai-resume 代码进入本包**，抽取许可问题在 3.2 未被触发——这不放宽 `ai-resume` 所有权仍为 `[!]` 的前置门禁（3.3-13 / 3.4-09 若真要抽取才生效）。
