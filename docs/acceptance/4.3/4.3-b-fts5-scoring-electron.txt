== A. INSERT ... ON CONFLICT ... RETURNING 在 node:sqlite 里能不能拿到 seq
  首次插入 → {"seq":1}
  同 chunk_id 再写 → {"seq":1}（两次必须同一个 seq，否则倒排会指错行）
  全表：[{"seq":1,"chunk_id":"c1"},{"seq":2,"chunk_id":"c2"},{"seq":3,"chunk_id":"c3"}]

== B. 事务里 ALTER TABLE ADD COLUMN + CREATE VIRTUAL TABLE 能不能成（迁移 13 的形态）
  成功：ALTER ADD COLUMN 与 CREATE VIRTUAL TABLE 可同事务；列数=6

== C. 倒排维护：DELETE rowid 后再 INSERT 同一 rowid，然后 OR 查询
  fts 行数=3
  MATCH "订单" OR "库存" → [{"rowid":3,"s":-0.5914823012027262},{"rowid":1,"s":-0.4495265489140719}]
  MATCH "订单" OR "并发" OR "缓存" → [{"rowid":2,"s":-1.0216512475319814},{"rowid":1,"s":-0.4495265489140719}]

  MATCH "订单" → [{"rowid":1,"s":-0.4495265489140719}]
