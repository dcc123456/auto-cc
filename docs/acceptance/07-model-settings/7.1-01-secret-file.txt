# 权限这一条不是"顺手设的"：spike 实测 `fs.writeFileSync(..., { mode: 0o600 })` 在**已存在的文件**上不生效
# （createOnly 语义，默认落 0644），所以 `SecretStore.flush()` 在 rename 之后显式 `chmodSync(0o600)` 两次
# （临时文件与目标文件各一次）——上面的 mode=0600 就是这一步的产物，去掉它就会退成 0644。
