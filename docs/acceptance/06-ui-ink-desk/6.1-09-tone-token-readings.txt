6.1-09 色相半边（第四十二片）— 毡案语气色在令牌层压深的求解、机检与活体读数
================================================================================
执行时间：2026-10-08（本机 macOS / Apple Silicon）
裁定（AskUserQuestion 原文）：「令牌层再压深毡案语气色」
  —— 三条备选（把消费者逐点改挂 -ink / 接受次 AA / 只动 wash）都不是这一条：改的是
  `[data-theme='light']` 里四档 `--color-<tone>` 与 `--color-<tone>-ink` 的**色值本身**，
  一次改值让 `Banner` / `Tag` / `EffectChip` / 语义按钮 / 按钮结果态五条载体同时过 AA。

--------------------------------------------------------------------------------
0. 口径与工具
--------------------------------------------------------------------------------
- 亮度系数用 WCAG 的 0.2126 / **0.7152** / 0.0722（第四十一片窗口里误写过 0.7126，本轮全部读数
  已按正确系数复算；这一位差别会把比值压低约 0.03，不影响判定方向）。
- 半透明淡洗**不当成 solid 色**：沿祖先链向上取到第一只不透明底，逐层 alpha 合成后再算比值
  （`tmp/42-tune.js` 的 `stack()`，与机检第 12 节同一算法）。
- 门槛：≥12px 文案 4.5:1（AA 正文）；≤11px 次级读数沿用本项目既定的 3:1 档（`globals.css:280` 的
  那条实测：毡案 jade/amber 曾按 3:1 反推加深过）。
- 承载面取**五级**：`bg-ink-750`(#d4cebd) / `bg-ink-950` / `bg-ink-900`(#e7e3d8，纸面) /
  `bg-ink-850` / `bg-ink-800`。ink-750 是活体普查里找出来的最差那只（不是纸面），
  判据按"五级里最差的一面"收，因此 `Banner` 压在长条中性底上也一起过。
- 同色实底另核一档：语义按钮用 `bg-<tone>/14`（jade/amber）与 `bg-seal/18`，青瓷没有这种载体，
  所以按档给值而不是给统一区间。

3. 机检第 12 节（令牌层，离线，不需要浏览器）
--------------------------------------------------------------------------------

    语气洗底 0 处、≥12px 灰阶档 0 处，四档语气文字档 × 两案 × 五级承载面 × 两种同色底全部 ≥4.5:1）

6. 唯一一条低于 AA 的语气行：嵌套载体（同色淡洗叠同色淡洗），按既定 3:1 档记为 findings
--------------------------------------------------------------------------------
定位（`tmp/42-find.js`）：接管卡 `TakeoverBanner.tsx:70` 在一支 amber `Banner` 里又放了一只
`variant="amber"` 的 `DeskButton`——底色是"amber wash 叠 amber wash"，比机检射程里的单层载体更深。
  毡案读数 4.38（文字 #654507，合成底 #c2b79e，字号 **11px**）；同一行墨案读数 5.46。
若要把这一形状也压到 ≥4.55（`tmp/42-solve2.mjs`）：
  celadon 需 k=0.562 #234843｜jade 需 k=0.568 #174531｜amber 需 k=0.594 #523806｜seal 需 k=0.470 #5a1b0f
两条否决理由（所以不追）：
  ① 深到 #5a1b0f 这一级后，四档在毡案上已经比稿上 `--seal-deep`（#96290f）还深两档，淡洗与描边会
     一起沉成"脏墨"，那是设计层的事，不属于一次对比度修复；
  ② 同一形状换到墨案（文字档早已存在、本轮未动）读数是 jade 3.97 / seal 3.88 / amber 4.34 /
     celadon 4.49——也就是说"叠两层同色底"这一形状在两案里都不是靠令牌能解决的，
     它属于"该不该在提示条里再放一只同色按钮"的组合问题。
按 §0 不自行打破规则：这一行**不静默放行**（写成 findings 并留读数），也**不在本轮擅自改组件组合**
（那会动 6.2-18 已 `[x]` 的接管卡布局）。它落在本项目既定的 ≤11px 次级 3:1 档上（4.38 ≥ 3，达标）。
