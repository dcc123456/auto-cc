③ 三条退出路 + 切视图（纪律表「Esc 层级」「焦点」两行）
----------------------------------------------------------------------------------------------------
全部在同一份活体页面上跑完，每一段都先重开一次抽屉（`[data-action=snapshots]`）：
  · Esc：`escOpened=true → escClosed=true`（合成的 `KeyboardEvent('keydown', {key:'Escape'})` 派发在 window 上，
    只验"监听有没有跑"，不是可信输入；层级 LAYER_DRAWER=20 归它收）
  · 点遮罩：`scrimOpened=true → scrimClosed=true`
  · 右上角 ✕（`[data-action=snapshots-close]`）：`xOpened=true → xClosed=true`
  · 开着抽屉切左栏：`chatSelected=true`、`drawerVisibleAfterSwitch=false`、`scrimVisibleAfterSwitch=false`、
    `drawerStillMounted=true`（六个视图常驻挂载，`hidden` 祖先把 `fixed` 后代一起藏掉＝§3.8 那条"同一时刻 ≤1 只遮罩"）
  · 切回简历：`drawerBackVisible=true`（**状态存住**，抽屉还开着）；`diffBackVisible=false` 是重开时
    `loadSnapshots` 把 diff 清掉，不是丢状态
  · 收尾 `leftOpen=false`（把界面留在干净状态给人接手）
焦点环与"关掉后焦点还给触发者"这一路走的是 `useOverlayBehavior` 同一份实现（第二十五片已取过真鼠标读数）；
本片用合成 click 打开时 `document.activeElement` 是 body，触发者本就记不到，故不在此重复取证。

⑥ 与稿的偏差（逐条如实记，不偷偷补也不假装做过）
----------------------------------------------------------------------------------------------------
(a) 稿 4-A 头部是一条 segmented「v7 → v6」选版本对；实现把版本对放在栏内首行（两只 `DeskSelect`），
    标题栏只放标题 + 份数。分界不变：栏内仍是"两栏并排比"的那一栏。
(b) 稿上换版本对**即时**出差异；实现是"选完再按一次「比对差异」"。理由：连改两只 select 时前一条请求还在途，
    它的结果会贴到新版本对上（界面说谎），而即时重比要么丢弃后一条、要么给差异再存一份归属，两条都比多一颗键贵；
    按一次比一次还让"上一条还在途"这条原因码由 `DeskButton` 说给人听（07 稿④）。
(c) 稿 `.drawer` 通用档是 `top:46px; bottom:30px`（不盖标题条与状态条），而 09 稿形态④ 的两张样张把它显式钉成
    `top:0; bottom:0`（全高）——实现按样张那一档做全高。随之带出一条既有事实：遮罩 `inset-y-0` 会盖住标题条与
    状态条（`elementFromPoint` 在两处都命中遮罩，`rgba(4,7,10,0.66)`），而 `SCRIM` 那行注释写的是"不盖住状态条"。
    这一条对弹窗与抽屉同时成立、且早于本片存在，本片不改，只记在这里。
(d) 稿 4-A 的三条写动作（全部丢弃 / 保留勾选项 / 回到这一版）**一条都没实现**：渲染层能问到的只有
    `resume.snapshot.list` 与 `resume.snapshot.diff` 两只读口（`packages/shared/src/bridge.ts:2294/2299`），
    没有回滚/丢弃通道。不装按了什么都不发生的按钮。
(e) 稿 4-A 每行带「来源」（谁存的这一版）；`SnapshotMetaView` 只有 `snapshotId/templateId/createdAt/hash`，
    没有来源字段 → 选择器一行只有「模板 · 时刻 · hash 前缀」。
(f) 稿 `.drawer .row` 字号 12px；实现沿用本面板既有的 11px 读数字阶（改字号会牵动 6.1 字体阶那批已入库读数）。
(g) 见 ⑤：窄窗那一档只取了产物规则，未取画面。
