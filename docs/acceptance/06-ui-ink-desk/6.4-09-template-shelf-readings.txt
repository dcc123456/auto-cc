6.4-09 模板架：50 套版式骨架缩略图 + 按轴筛选 + 默认印章 + 设默认后现读偏好
==========================================================================
取证时间：2026-10-10。探针：tmp/g7/desk-flow.mjs（段三）、tmp/g7/shelf-leg.mjs、tmp/g7/shelf-shot.mjs。
画面：6.4-09-template-shelf-filtered.png（毡案，筛「双列」那一轴之后）。

一、U 半边（轴投影的一致性断言在哪一支测试里）
---------------------------------------------------------------------
`pnpm --filter @auto-cc/resume-doc test`（整测那轮起）——逐套断言 `layout` 七条轴与注册表
`TemplateSpec` **一字不差**、且 `Object.keys(layout)` 不多不少就是那七条的用例，
落在 **`packages/resume-doc/src/preference.test.ts`**（用例名「模板摘要把七条版式轴一字不差地带出去」）。
spec 行原文写的是 `template-library.test.ts`，那份文件在本仓不存在——状态位更新时把这一格改成实际位置，
不改判据本身。

二、C 半边
---------------------------------------------------------------------
`pnpm lint` 绿（EXIT=0）：强调色走 15 条字面量 class 表（`ACCENT_BAR_CLASS` / `ACCENT_EDGE_CLASS`），
没有动态拼 class；`src/ui/**` 之外的 hover/禁用原因码/裸控件/灰阶档四条机检同批绿。

三、V 半边：筛选是双向的，且计数说的是人话
---------------------------------------------------------------------
未筛时          count = "共 50 套 · 当前筛选剩 50 套"    卡片 50 张
按「栏数 = 2」  count = "共 50 套 · 当前筛选剩 5 套"      卡片 5 张     aria-pressed: columns-2=true / columns-1=false
再按同一档      count = "共 50 套 · 当前筛选剩 50 套"     卡片 50 张    （同颗键 = 取消这一轴，不是再筛一次）
· 轴组按数据现推：只有一档取值的轴不画（本库五组：栏数 / 抬头 / 标题 / 强调色 / 密度，
  段内 `[data-action^="shelf-filter-"]` 共 36 颗）。
· 当前出纸那一格：`shelf-selected` = "当前出纸：现代双列强调"，`[data-shelf-badge="default"]` **恰好 1 枚**（"默认"），
  `[data-action="remember-template"]` **恰好 1 颗**（"设为默认"只长在选中的那张卡上）。
· 诚实条款在明面上：架顶两行「点小图就改用这一套出纸；等宽小字是版式轴的技术读数」+ 收起的
  `DeskExplainer`「小图画的是什么」——真渲染 50 套这条明确不做（plan §3.26）。

四、设默认之后经 IPC 现读回来（不是界面自己记的）
---------------------------------------------------------------------
按 `[data-action="remember-template"]` → `window.autoCC.resume['export.preference']()` 回
  { ok: true, value: { templateId: "modern" } }
即"当前出纸：现代双列强调"（`modern`）确实落到了偏好库里，界面没有第二份事实。

五、限高那一格（同批修掉的病灶，读数见 6.4-07 第三节③）
---------------------------------------------------------------------
架体 `max-h-[min(52vh,440px)] overflow-y-auto`：clientHeight 401 / scrollHeight 1676（差的这两百多像素
就是"架子自己滚"的正读数：内容比可视层高，滚动条挂在架体上）——
50 套摊开时架子自己滚，不再把整屏撑到六千像素（整屏 6032 → 1849 的两档读数见 6.4-07 第三节③）。
筛剩 5 套时**没有另取架体高度读数**，能给的实测是单张卡片 `cardBox.h` = 203px（5 套一行摊得下），
以及这一跳的卡片数与计数行确实回到了 5（上面第三节）——判据落在"计数与卡片数一致"，不落在高度上。
