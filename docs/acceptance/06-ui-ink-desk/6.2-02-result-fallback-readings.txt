⑥ 一处只能如实标出来的环境限制
────────────────────────────────────────────
· 成功态的 wash 带 `animate-wash`（`wash 2s ease-out forwards`，关键帧 0 → 1@18% → 1@78% → 0），
  而窗口 hidden 时 Chromium **不推进 CSS 动画时钟**，于是这一层的 opacity 一直停在 0：
  颜色在节点上（`rgba(47,143,102,.12)` / `rgba(79,183,138,.12)`），画面上不上色。
  失败态的 wash 没有动画，opacity 恒为 1，所以 ④ 的裁切图看得到朱砂底。
· 因此 `6.2-01-result-jade-*.png` 里可见的凭据是**角标与描边**，青玉 wash 的可见上色要等
  用户在场、窗口带到前台时再取一次（与 6.2-01 悬停那一腿同一门槛）。
· 另记一次迟到：对照趟（`res22.mjs`）里毡案那一轮在 2.8 秒时成功态**仍在**，
  随后（约 5 秒）才撤。归因是同一类——hidden 窗口里 `setTimeout` 被节流。
  正式一趟两档都按时回落，故回落判据按 ③ 记；这条不写成"已排除"。
