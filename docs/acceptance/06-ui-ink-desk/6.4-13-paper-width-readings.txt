6.4-13 · 右栏宽度可拖拽并持久化（抽成 `src/ui/split.tsx` 一处实现）——活体读数
================================================================================

取证对象同 6.4-12（用户自己的 dev 实例，CDP 10222 / 5173，窗口 1200×772，容器实测 940）。
三支脚本各管一腿：`tmp/57b/legs57.mjs`（合成 pointer 拖拽 + 边界 + 键盘）、
`tmp/57b/reload57.mjs`（reload 持久化，**单独一条会话**：`Page.reload` 会打断这条 WebSocket 的
Runtime 上下文，同一会话里等回执直接挂住——本轮第一版挂了两分钟）、
`tmp/57b/kernel57.mjs`（内核视图那侧的回归负腿）。

先记一条**读法**，否则下面的数字会被读反：把手长在纸栏的**左缘**，所以"向左拖是变宽"，
与 `KernelViewSlot` 同一条口径（方向按**手势**不按"值变大"）。脚本里的参数因此写成
"想要的纸栏百分比"，而不是"指针往哪边走"。

还有一条：每一腿都读两遍——`…` 是同一任务里的即时读数，`afterFrame` 是**逼一帧之后**的读数。
hidden 窗口里 `ResizeObserver` 排在帧末，即时读数拿到的是"宽度已改、倍率还没重算"的中间态
（例如 `dragTo50` 的即时 `neverClipped:false` + `frameRectWidth:470`，逼帧后收敛成
`neverClipped:true` + `414`）。**判据以 `afterFrame` 为准**，中间态留在这里说明为什么要隔一帧。

④ 判据③ 的后半：reload 之后仍是那一档（`reload57.mjs`）
----------------------------------------------------------------------

$ node tmp/57b/reload57.mjs tmp/57b/persist 47
BEFORE_RELOAD       {"mounted":true,"ariaNow":"56","inlineVar":"56%","colWidth":526,"stored":"47","direction":"row"}
AFTER_RELOAD        {"mounted":true,"ariaNow":"47","inlineVar":"47%","colWidth":442,"stored":"47","direction":"row"}
AFTER_CLEANUP_RELOAD{"mounted":true,"ariaNow":"56","inlineVar":"56%","colWidth":526,"stored":null,"direction":"row"}

→ 把盘上写死成 47 再 reload：`aria-valuenow` 从 56 变成 **47**、列宽 526→**442**、内联变量 `47%`——
  起手档是从 localStorage 读回来的，不是组件默认值。第三行是收尾：擦掉键再 reload，回到默认 56，
  **用户的实例不留我拖过的那一档**（`stored:null`）。
  `BEFORE_RELOAD` 那行的 `ariaNow:56 / stored:47` 是同一条判据的反面自证：DOM 还没重挂载时，
  盘上的值与画面上的值可以不一致，所以判"持久化生效"必须看 reload **之后**。
