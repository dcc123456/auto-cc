6.2-20 行/卡片去语气洗底 —— 探针 + 活体读数（本机 macOS，CDP 10222，渲染层 --url 5173）

判定：行/卡片族把「语气」从**底材**挪到**描边**。收敛前那批行把 `bg-*-wash` 拼在行上，
      一次 run 里 pending/running/done/failed/skipped 会各自长出不同底色（色斑列）；
      稿上的行/卡片从不这样画——状态只上描边，底材恒为墨面档。
      本片把这条收进 L1（`BLOCK_EDGE_CLASS` / `BLOCK_SURFACE_CLASS` / `BLOCK_SELECTED_CLASS`），
      面板只交语气档名，`bg-*-wash` 在 `src/ui/**` 之外归零，并补上机检。

取色口径：Tailwind v4 的 `getComputedStyle` 回 `oklab(... / a)`，正则解析失败；
          用 1×1 canvas（fillStyle + getImageData）解任意 CSS 色，
          半透明 wash 先沿祖先链累加到首个不透明底再合成，才拿到落点色（不是 wash 自己的色值）。
          `toneTinted` = 该行合成底材是否偏离 `bg-ink-850` 参考面；false 即「底材没跟语气走」。

════════════════════════════════════════════════════════════════════════
1. 去洗底达成：两主题下 AFTER 四色语气档的 toneTinted 全部 false，底材锁死在 bg-ink-850，
   语气只由描边（BLOCK_EDGE_CLASS[tone]）承载——一次 run 不再长出五颜六色的行底。
2. 对比度顺带改善（墨案）：seal 行文字/底从 4.46 → 4.83（越过 AA 4.5）；
   jade 6.43→7.36、celadon（原 slate-100 白字 12.22，改语气字后 7.98）、amber 7.02→8.23。
   描边对底：seal 4.46→4.80、jade 6.37→7.36、amber 7.07→8.29 均升。
3. 毡案语气作字仍偏低（jade 3.83 / celadon 3.32 / amber 4.08 / seal 3.95，AA 4.5 以下）——
   这条与本片无关，是**令牌层**的既有待表态项（毡案 tone-as-text 加深 / 或接受稿值），
   本片不逐点打补丁；记录在案，见 plan §3.13 与本文件末尾。
