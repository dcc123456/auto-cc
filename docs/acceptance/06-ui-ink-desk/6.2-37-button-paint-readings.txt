一、几何普查：信任屏上 35 只可见按钮（脚本 `tmp/6237-probe.mjs`，聚合 `tmp/6237-parse.mjs`）
--------------------------------------------------------------------------------------------

判据两条，都是"读 DOM 的几何"而不是"读 class 字符串"：

1. **图标与文案不许换行** = 一只按钮里所有可见墨迹（文案节点用 `Range.getBoundingClientRect()` 现量，
   图标用 `svg` 的矩形）必须落在同一条横带上：`max(top) < min(bottom)`。
2. **文案前面不许有空白** = `headGap = min(墨迹左缘) - 按钮左缘 - 1px 描边` 必须 **等于左内边距**，
   多出一分都算（旧缺陷就是多出 14px 槽位 + 6px gap = 20px）。

读数（`selectedView=trust`，`count=35`，注入冻结后 `anim=0`）：

| 项 | 读数 |
| --- | --- |
| 分行（`sameLine=false`）的键 | **0 只** |
| `headGap − (左内边距 + 1px 描边)` | **min = −1，max = 0**（负 1 是亚像素取整，不是空白） |
| 高度档 | **19 / 24.1 / 30 / 30.1 / 32** 五档 |
| 带 `doneLabel` 那一族（`open` / `probe` / `logout` / `close-view` / `snapshot` / `navigate` / `settings-model-*`）| **24.1px**（改版前同一族 **35–38px**：preflight 把 `svg` 画成 `display:block`，图标孤零零压在文案上面，多出一整行） |
| 状态角标已渲染（静止态） | **0 只**（角标只在 busy / 结果态长出，静止态不占位） |

逐档样本（`w / h / padLeft / headGap`）：

```
h=30   pad=12px headGap=13 → 4 只   shell-theme-toggle(115) / shell-language-switch(84.1) / privacy-open(103) / refresh(140)
h=32   pad=10px headGap=10 → 5 只   nav-chat / nav-jobs / nav-resume / nav-workflow / nav-trust（各 167）
h=30.1 pad=10px headGap=10 → 1 只   nav-diagnostics(167)
h=24.1 pad=8px  headGap=9  → 24 只  open(78) / probe(89) / logout(80.6) / close-view(100) / snapshot(102) / navigate(56) / send(115.6) / audit-refresh(55) / settings-model-*(80)
h=19   pad=8px  headGap=9  → 1 只   kernel-slot-show(31，只有图标没有文案)
```

`headGap` 与左内边距逐位对得上：`12px + 1px 描边 = 13`、`10px + 描边 = 10~11`（导航格左缘还带一根
`before` 短线的负边距，量到的是文字起始位）、`8px + 1px = 9`。**没有一只多留那 20px**。

带 `doneLabel` 的那一族 `inkCount=3` 而 `headGap` 仍是 9，是因为两句话叠进同一个 grid 单元格后
**不可见那句照样占宽**（6.2-01 的宽度锁死），而它们的左缘都是同一格里的图标：
`close-view` 两句分别在 `@230`（已关闭视图）与 `@246`（关闭内核视图），图标 `@230`，取最小者 230。

二、五态锁宽 + 角标几何（脚本 `tmp/6237-badge3.mjs`，MutationObserver 抓角标进/出 DOM 那一拍）
------------------------------------------------------------------------------------------------

取数对象是 `close-view`：信任屏上唯一一条**纯本机、可逆、且带 `doneLabel`** 的动作
（它关的是内嵌内核视图，不发消息、不碰平台）。总共 5 拍：

| 拍 | `w` | `h` | `data-result` | `data-disabled-reason` | 角标 | 可见墨迹 |
| --- | --- | --- | --- | --- | --- | --- |
| rest（点之前） | 100 | 24.1 | null | null | 无 | `关闭内核视图@246`、`icon@230` |
| mutation 1（在途） | 100 | 24.1 | null | `ACTION_BUSY` | 无 | 同上 |
| mutation 2（回结果） | 100 | 24.1 | `done` | null | `offTop -5 / offRight -5 / 18×18` | `已关闭视图@230`、`icon@230`、`icon@311.5` |
| mutation 3（回落） | 100 | 24.1 | null | null | 无 | `关闭内核视图@246`、`icon@230` |
| tail（3s 后） | 100 | 24.1 | null | null | 无 | 同上 |

四条要一起看的：
1. **换文案前后宽度逐位相同**（rest 100 → done 100）——这正是 6.2-01 卡了很久的第①支 V 读数；
   行高五拍都是 24.1，所以"换字不会挤行"同帧兑现。
2. **角标长在右上角压边处**：`-top-1.5 / -right-1.5` → 相对按钮矩形 `offTop = -5`、`offRight = -5`，
   尺寸 18×18。**它不占文案前面那一格**（`headGap` 五拍恒为 8，即 `px-2` + 描边），
   也不改宽度（第一版的缺陷就是角标排在文案后，按钮从 109px 撑到 127px）。
3. **锚点 `data-result-text` 换到了包裹 `<span>` 上**，值在 `idle`↔`done` 之间翻；
   判据读 DOM 可见性（表里"可见墨迹"就是 `visibility!=='hidden'` 那两支），不读 `result` 返回值。
4. **回落时刻**：在途那一拍拿到的是 `data-disabled-reason="ACTION_BUSY"`（组件自己的门禁，
   不是原生 `disabled`，§9 的 6.2 第二十三/二十四片②），结果态约 2s 后回到 rest 形状。

四、机检第 15 节「按钮只有一张画法」（`scripts/check-renderer-conventions.ts`）
---------------------------------------------------------------------------------

三条判据，射程 = `packages/renderer/src/ui/**\/*.tsx`（原件层自己也在射程内，不留豁免）：

| 判据 | 机制 |
| --- | --- |
| ① `src/ui/**` 之外的裸 `<button>` | 第 10 节已有，本节不重复 |
| ② `src/ui/**` 里手写 `<button>` 的画法必须走**具名档位** | `className` 必须匹配 `\w+Class` 或 `[A-Z][A-Z0-9_]*_CLASS`；不带 `className` 单独报一句 |
| ③ 悬停画法不许写在 JSX 站点 | 同第 13 节，但本节把射程拉进原件层 |
| ④ **不许有只给尺寸不给内容的空 `<span />`** | `<span className="…(w|h|size)-…" />` 直接判死——这就是"文案前那一段空白"的机制本身 |

两条注入探针（各自 `npx tsx scripts/check-renderer-conventions.ts`，退出码不经管道）：

```
P1 一只内联画法的按钮 + 一支 w-3.5 空槽位   → EXIT=1，报 :3 画法写在 JSX 里、:3 内联 hover、:4 空 span
P2 一只完全不带 className 的 <button>        → EXIT=1，报 :3 不带 className
负对照（删掉探针）                            → EXIT=0，收尾日志含「src/ui/** 内画法未走具名档位的按钮 0 只、占位空 span 0 只」
```

一条实现层的坑（写进脚本注释）：判据取 `className={…}` 表达式时必须**配平花括号**。
原先用非贪婪 `className=(\{[\s\S]*?\})`，在 `${…}` 处就截断了，
把 `controls.tsx:1104 / :1204` 两格正常档位引用误报成"没走具名档位"。

六、如实记的边界与副作用
-------------------------

- **像素级"人眼看不出这是同一只按钮组件"没有兑现**：本次全部读数走几何与计算值，
  窗口 `visibilityState=hidden`，真鼠标事件不落页（§9 的 2.1-12）。**这一条留给用户在场**。
- 角标在 `overflow-hidden` 的行容器里会不会被裁：本片没量。信任屏的行容器没有 `overflow-hidden`，
  但 6.2-26 那条"光晕不被裁"的欠项同属这一族，仍在 6.2-26 名下。
- 取数时在用户 dev 实例上做的动作：acknowledge 隐私提示、切到信任屏、点 `close-view` 两次、
  点 `snapshot` 一次（失败态因此持久）。**全是本机动作，无外发、无真实平台导航、无写库**；
  `close-view` 关掉的视图是渲染层的内嵌槽位，用户随时可再展开。`snapshot` 那次失败没有留副作用
  （它要写的快照需要视图在场，一条都没落）。
- 冻动效的 `<style>` 已摘（`removed=true`），用户实例的动效恢复正常。
