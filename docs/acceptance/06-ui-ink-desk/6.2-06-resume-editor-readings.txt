6.2-06 第十三片取证：排版编辑器（`ResumeEditor`）换装后的活体读数
================================================================

时间：2026-10-06 09:00–09:06 UTC（一轮 `harness eval` / `shot`，脚本 `tmp/v6b/re1-*.js … re17-*.js`）
宿主：`pnpm dev`（`AUTO_CC_USER_DATA_DIR=tmp/v6-userdata`，CDP 10222），目标页 `--url 5173`
可见性：`document.visibilityState = visible`、`hasFocus = true`（所以截图与属性读数是同一轮取的，不是"只读数没画面"那一族）
方式：页面里 `getComputedStyle()` + `data-*` 现读；切主题走 `[data-action=shell-theme-toggle]`。

令牌基线（下面的"对上"都以这几个值为尺）：
墨案 `seal = rgb(226,84,58)`、`amber = rgb(224,163,63)`、`celadon = rgb(127,182,173)`、
`line = rgba(150,178,196,.14)`、`line-strong = …/.26`、`ink-950 = rgb(8,12,16)`；
毡案 `seal = rgb(192,57,31)`、`amber = rgb(161,112,15)`、`celadon = rgb(63,128,120)`、
`line = rgba(38,44,48,.15)`、`line-strong = …/.30`。
**组件里零 `theme ===` 分支**：两套读数是同一份 class 在两个 `data-theme` 下的结果。

一、七只键位的归属与禁用理由（墨案，进入编辑器时的初始态 → 改动后）
--------------------------------------------------------------------

| `data-action` | `data-effect` | 归属理由 | 禁用态读数 | 可用态读数 |
| --- | --- | --- | --- | --- |
| `close-editor` | `ghost` | 干净时只是卸载组件，什么都不发 | 在途才禁（`ACTION_BUSY`） | 边框/底 `rgba(0,0,0,0)`、字 `rgb(164,182,195)`，w 109 / scrollWidth 107（不裁字） |
| `close-save` | `amber` | 写的是本机库里的那一份草稿 | — | 边框 `oklab(0.756171 …/0.4)`、底 `…/0.14`、字 `rgb(224,163,63)` |
| `close-discard` | `seal` | 不可逆：丢掉的是内存里唯一的一份（裁定⑨ 之后没有第二次入口） | — | 边框 `oklab(0.631608 …/0.45)`、底 `…/0.18`、字 `rgb(226,84,58)` |
| `close-stay` | `ghost` | 只把确认卡收回去 | — | 全透明底 + `rgb(164,182,195)` |
| `undo` | `ghost` | 回退是本机内存动作 | `aria-disabled=true`、`data-disabled-reason=NOTHING_TO_UNDO`、`title="没有可撤销的编辑了"`、字退成 `rgb(108,128,145)` | 改动一步之后同一颗转亮 `rgb(164,182,195)` |
| `redo` | `ghost` | 同上 | `NOTHING_TO_REDO` + 人话版 title | 本片未取到可用态（没有"撤销之后再重做"这一发） |
| `save-editor` | `amber` | 唯一的写库口 `resume.editor.save` | `NOTHING_TO_SAVE` + `title="草稿与库里的一致，没有要保存的改动"`、禁用态退成中性墨（边框 `rgba(150,178,196,.14)`、底 `rgb(15,22,28)`、字 `rgb(108,128,145)`） | dirty 后转 amber 档：边框 `…/0.4`、底 `…/0.14`、字 `rgb(224,163,63)` |

另有 3 只 `[data-action=drag-section]` 把手（非按钮，`data-effect` 空）：静置 `border rgba(150,178,196,.26)` = `line-strong`、
字 `rgb(133,152,168)`、圆角 4px；按下那一档（`celadon/70` + `text-celadon`）要真实拖拽才看得到，属 6.5-04 那一条。

**为什么 `save-editor` 从 emerald 换 amber**（照 08 稿的口径往下改，不是照抄旧 class）：
墨案里 jade/emerald 是"已经办成"的读数色，只能给已读/已核；按下这颗之后才发生写入，风险方向是"要动到库"，
与第十二片 `pdf-edit-save-as`、第十一片 `pause-supply` 同一条归属。08 稿的逐控件表没有列到本面板这三颗
（`docs/design/ui-drafts/08-click-map.html` 里搜 `save-editor` / `close-discard` 无命中），
所以这一档是按 plan §5 的归属表定的，不是按稿抄的。

四、行为半边（V 判据取的是页面自己的回执，不是命令返回值）
----------------------------------------------------------

1. `seed` → `open-editor` 从 `aria-disabled=true / NO_SEED_DOC`（title「先落一份文档，预览与导出才知道拿哪一份」）转为可点；
   编辑器挂上 `docId=resume-demo`、3 只区块行。
2. 正文字号 10.5 → 11（界内）：`data-dirty` 转 `true`、`undo` 转亮、`save-editor` 从 `NOTHING_TO_SAVE` 转为可用 amber 档。
3. 同一只滑杆拖到最左端 1.5pt（界表下限是 6）：主进程拒 → 被拒行出现，
   读数 `这次改动被拒：out-of-bounds：baseFontPt=1.5 不在 6…24 之内`，而**值仍是 11**（拒的那一发没落到草稿上）。
4. dirty 下点 `close-editor`：只长出确认卡，编辑器仍在（`editorStillThere: true`）——拦截生效在卸载这一层。
5. 点 `close-stay`：`cardAfterStay: false`、`editorStill: true`、`dirty` 仍是 `true`（收卡片不动数据）。
6. 再点 `close-editor` → `close-discard`：编辑器卸载。重新 `open-editor` 后直接读到
   `baseFontPt: "10.5 pt"`、`data-dirty=false`（文案「与库里的一致」）、`save-editor` 回到 `NOTHING_TO_SAVE`——
   即"只拦不存"（裁定⑨/⑪）在界面上兑现：丢掉的那一步从未落库，界面上也没有留下任何"看起来存了"的读数。
7. 干净态再点 `close-editor`：确认卡**没有**长出（`close-confirm` 不在 DOM），编辑器直接卸载
   （`editorStill: false`）——拦截只做在有未保存改动的那一档。
8. 全程 `save-editor` / `close-save` 一只没按：`resume-notice` 到最后仍是 `已载入演示文档 resume-demo`，没有保存回执。
   本轮写进磁盘的只有第 1 条那一份演示文档（`seed`，落在被 git 忽略的 `tmp/v6-userdata` 开发档里）。

七、没取到的（诚实记账）
------------------------

- `redo` 的可用态：要"撤销一步之后再重做"才长，本轮为保持末态干净没有走那一发；代码位与原因码齐（`NOTHING_TO_REDO`）。
- 把手按下那一档（`celadon/70`）与落点虚线（`border-dashed border-celadon/70`）：需要真实指针拖拽，属 **6.5-04** 那一条。
- `busy` 转针态：本面板每一趟往返都在一次 eval 的间隙里回来了，没抓到 `aria-busy` 那一帧；组件侧 `busy={!!busy}` 已接。
- 结果态角标（`useDeskResult` 的 done/failed wash）：本面板没有接 `result`，与第十二片同口径（回执走 `notice` 行）。
- Windows / linux 运行期：本机 macOS arm64，不适用（AGENTS.md §9）。
