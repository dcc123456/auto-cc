③ 键盘那一路（09 稿纪律表「焦点」行：抽屉与弹窗并列，Tab 在浮层内循环不出来）

     node-params-close → param-platform → param-job → param-title → param-company → param-text
     → param-save → node-params-close → param-platform      （环内 7 只，走到头自己回卷）

   ⇒ 左栏在鼠标那一路摸得到（②），在键盘这一路摸不到（③），两条同时成立才是形态④ 的口径。

⑥ 与稿的偏离（都按 §0 记下来，不自改也不 waived）
   (a) 稿上 4-B 是一列一字段：`OperatorParamForm` 原先带 `sm:grid-cols-2`，那是**视口**断列——
       1200px 窗口里它在 420px 抽屉内仍拆成两列、每列 177px，枚举候选与数字单位被截断。
       这一片把它改成单列（宿主只有抽屉一只消费者，两列那档已经没有宿主了，留着就是第二套形状）。
   (b) 稿上写「改动即写回画布，无需保存」，这一片**没有照做**：参数即时写回会换图指纹，
       而 5.10-07 要的正是「计划已修改 → 旧 run 不可续跑」、5.10-11 要的是运行期间画布只读，
       5.10-10 更已经把"改了就进库"判成比丢掉未入库编辑更糟的一条。所以保留「保存参数」显式提交，
       稿上那行 hint 不进界面。随之而来的第二条：`Drawer` 收起即卸载，**未提交的草稿文本会丢**，
       这与稿上"关闭不丢"不同——但稿上那句的前提就是"没有待提交的改动"，前提换了，读法按上面这条。
   (c) 稿上头部还有「取消 / 应用」两颗：✕ 与 Esc 与点遮罩已经是取消（④ 三条退出路），
       再放一颗「取消」是同一件事的第二个入口（§2.5）；「应用」就是既有那颗「保存参数」，键名与档位未动。
   (d) 稿上的「每站点上限」滑杆 + 「30 / 日（当前额度上限 45）」这一档**不做**：字段一律由算子的 zod
       schema 派生（5.10-04 的"表单由 schema 生成"），为一只算子在手写控件位上开例外，
       等于把通用表单降级成又一张 per-算子 卡；而"当前额度上限"是 usage.ledger 那一头的数，
       与节点参数不是一条读路径，不在这只抽屉里混着报。
   (e) 稿上「校验 通过 · 2 项警告」那种**警告/错误两分**没有：`checkWorkflowGraph` 回的是
       `WorkflowGraphIssue[]`（code + nodeIds + message），没有 severity 这一维，界面上不发明它。
   (f) 检视器那张卡（`rounded-xl border bg-ink-950/40`）在抽屉里仍是卡形，稿上抽屉体是裸字段。
       不去卡的原因：6.5-05 那行 `[x]` 的读数指的就是这只容器（毡案 `solid rgba(38,44,48,.15)` + `radius 12px`），
       去卡会让一条已验收的读数失效——与第四十三片"不动 6.2-18 已 `[x]` 的接管卡"同一条尺。
   (g) 运行读数卡（`WorkflowNodeDetail`）仍留在画布下方，没有跟着进抽屉：4-C 清单里只有「算子参数」
       这一只抽屉，读数卡说的是"这一格跑成什么样"，另属形态①/③ 的落点。
