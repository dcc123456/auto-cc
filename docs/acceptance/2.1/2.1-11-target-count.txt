##   泄漏的（例如只 forceUnload 不 close）会一直挂在表上——所以这是对端读数，不是 app 自述。

## 基线（挂载前）
  page  data:text/html;... Embedded kernel view placeholder (WebContentsView)
  page  auto-cc http://127.0.0.1:5173/

  {"startActive":"boss","cycles":10,"lastOpenedActive":"boss","lastClosedActive":null,"endActive":null}
  每一轮：open 后 activePlatform=boss，close 后 activePlatform=null（10/10 一致，见 tmp/2.1-11-cycles.js）

## 10 轮之后的 targets
  page  data:text/html;... Embedded kernel view placeholder (WebContentsView)
  page  auto-cc http://127.0.0.1:5173/
  => 2（与基线相同，未随开合次数累积）
