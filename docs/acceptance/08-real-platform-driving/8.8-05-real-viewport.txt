================================================================================
取证时间：2026-10-08 11:38–11:42，通道 `harness eval --port 10232 --url www.zhipin.com`
（读的是内嵌视图自己的 CDP target，不是 app 页面——AGENTS.md §9 的 2.1-12①：
 `shot --url 5173` 截不到原生子视图，但视图自己的 target 能读 DOM。）
页面：https://www.zhipin.com/shanghai/?seoRefer=index（右上角是用户本人账号，登录态在重启后仍在，
      说明 `persist:boss` 那份分区确实带着 cookie；账号名与头像不进本文件，见 §8.5）

--------------------------------------------------------------------------------
A. 横向：BOSS 首页是 1224px 起铺的桌面布局
--------------------------------------------------------------------------------
  槽位宽 659（55% 档，窗口 1200）  clientWidth  659 / scrollWidth 1224 → 横向溢出，页面被裁
  槽位宽 1015（展开，窗口 1200）   clientWidth 1015 / scrollWidth 1224 → 仍溢出（差 209px）
  槽位宽 1327（展开，窗口 1512）   clientWidth 1327 / scrollWidth 1327 → **不再溢出**（`horizontalOverflow: false`）
  溢出样本（改宽前）：`DIV.` / `DIV.inner home-inner` / `DIV.nav` / `UL.` / `LI.`——是站点自己的定宽容器，
  不是我们的样式表；改宽后溢出样本只剩 `UL.cur`（导航当前项，非布局裁切）。
  注：最窄的 38% 档（455px）没有单独采过站点读数——它比已实测的 659 更窄，溢出是同一方向的更甚情形，
  但这里不把它写成实测值。

  判读：用户报的"网页显示不全"根因是**几何**，不是渲染缺陷——固定 38% 只有 455px，
  而 BOSS 的桌面布局最小 1224px。所以这一片的交付口径是：
  ① 三档宽度 + 展开占满工作区把可选宽度拉到 1015（1200 窗口）/1327（1512 窗口）；
  ② 要完全不横向裁切，需要**展开档 + 把 app 窗口拖到 ≥1410 宽**（185 左轨 + 1224 站点最小布局）。
  这条是产品事实，写在这里而不是藏在截图里：小窗口下仍会横向溢出，界面没有骗人说"已铺满"。

--------------------------------------------------------------------------------
B. 纵向：滚动交还给页面自己，可用
--------------------------------------------------------------------------------
  展开档（clientHeight 654 / 798）下 `scrollHeight` 恒为 3736（首页长页），
  `window.scrollTo(0, 800)` 后回读 `scrollY = 800`，再归 0。
  判读：视图尺寸 = 站点视口尺寸这条等式成立之后，滚动条与滚轮都是页面自己的原生行为，
  app 不代它滚（也没有另写一条滚动通道）。真实鼠标滚轮落不落在页面上属于"人要在场"那一档，
  本条读数只证明**页面具备可滚动的视口**，不证明指针事件（§9 的 2.1-12）。

--------------------------------------------------------------------------------
C. 反向验证（§6.5）
--------------------------------------------------------------------------------
  没有为了"看起来铺满"去伪造 UA 或注入 viewport 覆盖：`document.title` 与站点自己的布局宽度
  都是原样读数，Electron 默认 UA 未被改写（8.0-01 已实测真站点不拒这个 UA），
  `check-compliance-redlines.ts` 的 UA/指纹规则一字节未改。
