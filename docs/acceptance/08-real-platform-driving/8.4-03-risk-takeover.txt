      bodyHas:['验证码','安全验证','滑块','拖动','请完成验证'] 过滤结果 = [] ,
      captchaNodes: 三个 IFRAME，className 与 id 均为空 }

    { isHeld:false, reason:null, startedAt:null, beginCount:0, endCount:0 }

两条要分清，别把这一格写成"验过了"：
- **`bodyHas` 为空只说明这轮没出现这几条文案**，它不是"风控检测能力已到货"的证据——这一路的能力面
  只在仿站替身上被正面验过（spec 2.3-05 / 2.6 那批），真站点上从没主动触发过一次。
- 那三个无类名无 id 的 IFRAME 是站点自己的埋点/宿主帧，**没有**被当成风控凭据读，也没有为它们做任何判定。
