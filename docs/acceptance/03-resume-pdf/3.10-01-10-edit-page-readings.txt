`topMm` 合法 5…40。

段级五格（`tmp/310/p-d-axes.js` + `p-d2-numeric.js`，选中段种类 `summary`）：

| 格 | 改动 | 纸面读数（帧内 `getComputedStyle(documentElement)`） | 撤销 |
| --- | --- | --- | --- |
| 字号 | 拨到 `23.5`（合法上界 24 之内） | `--rz-p-summary-size = 23.5pt`，且 `[class~="rz-summary-size"]` 计数 0→1 | 见下 |

撤销单元逐条对账（这是判据里"每一次改动 = 一个撤销单元"那一句）：

- 改动前 `undo = NOTHING_TO_UNDO`、`dirty = false`；拨完字号那一下 `undo = null`（可按）、`dirty = true`、
  `rejected = null`。
- 连撤两步的读数：`step1 { size: "23.5pt", lh: null }`（**只把行距撤掉**，字号还在）→
  `step2 { size: null, lh: null, dirty: false }` → 撤到 `NOTHING_TO_UNDO`。
  两步各自只回一条轴 = 两条轴各是一个撤销单元，不是一笔总账。
- 离散三格（对齐 / 字重 / 字色）各改一次后连撤三步：`undoWalk.steps = 3`，撤完 `dirtyAtEnd = false`、
  `undoReasonAtEnd = NOTHING_TO_UNDO`。

整份文档那六格（右栏）：

- 基准字号拨到 `23.5 pt`：帧内 `html` 计算字距从 `14px` 变 `31.3333px`、`line-height` 从 `21px` 变 `47px`

- 上边距拨到 `39.25 mm`：第一段离纸顶从 `57px` 走到 `153px`（左边距没动，`60→60`，说明只改了这一边）。
