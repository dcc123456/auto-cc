一、伴生 CLI 契约的无副作用实测（选的是"文件不存在"这一条：不建窗口、不碰任何真文件）

$ which officecc
/Users/dcc/.local/bin/officecc

$ officecc --version
officecc 0.11.0

$ officecc --json open /tmp/does-not-exist.pdf
{"status":"error","command":"open","code":2,"error":"file_not_found","message":"file not found: /tmp/does-not-exist.pdf"}
EXIT=2

这一枚原样进了单测（判据 3.15-03），字段名 `status / command / code / error / message` 与伴生应用
`packages/cli/src/result.ts` 的 `JsonError` 逐字对上。两处名字以本机读数为准、不按文档猜：
`ErrorReason` 里是复数 `outside_allowed_roots`（不是 `outside_allowed_root`），
`open` 用的页号开关是 `--page`（1 起）。EXIT=2 是"参数/前置条件不对"那一档，与 `status:'error'` 同时出现。
