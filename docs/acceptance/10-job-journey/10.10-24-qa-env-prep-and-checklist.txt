## 一、环境准备（一次性，可复现）

### 1. 交接用的全新 userData

- 目录：`/private/tmp/qa15-novice-ud`
- 内容**只有**一个文件：

```json
{ "platform-boss": { "pack": "fixture" } }
```

- 为什么用预置文件而不是界面保存：`pack` 没有界面落盘通道（`ConfigService.setPersisted` 在本仓**没有任何调用方**，且键白名单里没有它），改运行期 `plugins.saveConfig` 又只在内存、重启即失。持久层层级是 `default < file(cordis.yml) < persisted(settings.json) < env < runtime`，所以把 `pack` 写进 `settings.json` 是唯一「重启后仍然是仿站」的干净做法。
- 交接目录保持**首次启动状态**：我验证机制用的是另一个一次性目录 `/private/tmp/qa15-envcheck-ud`，验证完即弃；`qa15-novice-ud` 里没有 `store.db`、没有会话分区、没有隐私确认痕迹。

### 2. 本地仿站

- 进程：`packages/main` 同仓脚本 `tsx scripts/fixture-server.ts`，监听 `127.0.0.1:10233`
- 就绪判据：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:10233/boss` → `200`
- 该站点**只有回环地址**，不产生任何真站请求

### 3. 启动方式（萌新用同一条命令）

```
env -u ELECTRON_RUN_AS_NODE \
  /Users/dcc/deepseek-harness-workspece/auto-cc/dist/mac-arm64/auto-cc.app/Contents/MacOS/auto-cc \
  --remote-debugging-port=<自有端口> \
  --user-data-dir=/private/tmp/qa15-novice-ud \
  --disable-features=CalculateNativeWinOcclusion
```

> 注意：本机 shell 常带 `ELECTRON_RUN_AS_NODE=1`，不 `env -u` 会让 Electron 以纯 Node 跑、`app.isPackaged` 直接报错（本轮踩过一次，表现是 CDP 端口不监听）。

## 二、交给萌新的复测清单（他本人只点界面）

1. 起手：确认 `http://127.0.0.1:10233/boss` 为 200（若不对**只记卡点，不自行修环境**）。
2. 用上面那条命令启动；看到首屏的瞬间记为 `T0`。
3. 只走界面：简历准备（粘贴文字 / 虚构样例 / 文件面板任一路）→ 搜岗（本地仿站）→ 定制或打招呼 → 授权 → 仿站首次成功外发；外发成功那一刻记为 `T1`，判据 `T1 − T0 ≤ 10 分钟`。

5. 卡点必须 ≤3，每条写：看到什么、试了什么、为什么走不下去，附截图（截图只截证据区、不含个人数据）。
6. 顺带核：有无裸 i18n key、有无死路（点了没有任何反应/没有下一步）。
