# 10.11-32 补充：BOSS 九维筛选全部取值码（只读采集，零点击）

## 方法：为什么这次不需要点

上一轮（`10.11-32-qa-boss-param-collection.txt`）的结论是「param 名与取值码必须点一次看 URL 变化」——那个结论对**param 名**成立，对**取值码**不成立。
本轮改只读通道：筛选项的 DOM 上确实只有 `li[ka=...]`（`sel-business-N` 这类只带序号、不带码），但页面是 Vue 2，
`document.querySelector('.condition-industry-select').__vue__` 能拿到 `ConditionIndustrySelect` 组件，
沿 `$parent` 上去是 `FilterCondition`，它的 `$children` 里每一栏组件都把**完整取值枚举**放在 `$props.list` / `$data` 里，
元素形状是 `{ code, name }`（薪资另带 `lowSalary`/`highSalary`）。

所以：**展开下拉、点选项、翻页都不需要**。一次 `Runtime.evaluate` 读完九维，页面零交互、零导航、零外发。

## 多选维度在 URL 里怎么拼（从页面自己的解析代码读出，不是猜）

`PageJobs.initParams` 的源码原文（Vue 方法是可读的，`minify` 但结构完整）：

```js
Object.keys(Y).forEach(function(i){var n=Y[i];if(void 0!==e[i]&&""!==e[i]){var r=Array.isArray(e[i])?e[i].filter(function(t){return null!=t&&""!==t}).join(","):e[i];if(""===r||null==r)return;var s=(null==n?void 0:n.multiple)?String(r).split(","):r;t.$set(t.formData,i,s)}})
```

读法：**同一维度多值用英文逗号拼**，且页面按 `Y[i].multiple` 决定要不要拆。所以：

- 单维多选（`experience` / `degree` / `scale` / `stage` / `position` / `industry`）：`experience=105,104`，页面会拆成数组；
- 单选（`jobType` / `salary` / `city` / `multiBusinessDistrict` / `multiSubway`）：直接给单值；
- 「不限」的码是 `0`，与「不传这个 param」不是同一件事——传 `0` 与不传都表示不限，但页面会把 `0` 记成已选状态。

## 与「每维只有一个取值」这条缺口的关系

spec 10.11-32 的 dated 注说「现在页面每维只提供一个取值，下拉里只有一项，与 BOSS 筛选条件不一致」。
本文件给出的是**真实取值的全集**（6 个单维共 43 个码、行业 145 个子项、职位类型 158 个子项、城市 373 个、上海区县 16 个、上海地铁 26 条），
开发可以据此把界面选项铺满；剩下要做的是映射与入参校验，**不是继续去真站采数**。
