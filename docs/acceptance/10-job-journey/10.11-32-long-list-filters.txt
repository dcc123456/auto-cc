10.11-32 补：九维全量码入库 + 长列表选择器（2026-11-23 第 5 轮裁定）

**数据来源（单一来源已写明）**：QA 的 `10.11-32-qa-boss-filter-enums.txt`（只读采集：从 Vue 2 组件树读
`$props.list` / `$data`，页面零交互；12/12 与早前点击 URL 实测交叉一致）。我用一次性脚本
（`tmp/g11/batch/parse-enums.mjs`，不入库）把那份文件里的 Markdown 表机械解析进 `boss.json`，**没有手抄任何码**。

**入库结果（`boss.json` 的 `search.enums`）**

| 维度 | param | 入库条数 | 与 QA 原始条数的差 |
| --- | --- | --- | --- |
| 城市 | `city` | 373 | 一致 |
| 上海区县 | `multiBusinessDistrict` | 16 | 一致 |

| 职位类型 | `position` | **134** | 原始 158：**24 个名称在多个分组里重复**（如「技术项目管理」同时属「互联网/AI」与「电子/电气/通信」），下拉按名称索引只能保留一条，取第一次出现的码 |

「不限」不入码表：它等价于不传这一维，放进码表只会让「已筛」与「没筛」看起来一样。
多选本轮**未启用**：知识包没声明 `search.multi`，按设计口径一律单选；`subway`（地铁 26）也没有对应契约字段，**不入库**。

**职位类型接通三个地方**（设计 §7 的接缝）：`@auto-cc/shared` 的维度清单、`JobSearchCriteria` 与
`JobSearchCriteriaView` 的字段、`boss.json` 的 `params`/`enums`，渲染层标签键 `jd.filterLabel.position`
（职位类型 / Job category，与「求职类型 jobType」区分开）。

**长列表选择器**（按设计师 `docs/design/proposals/2026-11-23-long-list-filters.md`）
- 阈值 `OPTION_PICKER_THRESHOLD = 12`：≤12 用既有 `DeskSelect`（经验/学历/薪资/规模/融资/求职类型/区县），
  >12 换**原地替换**的选择器（城市 373、行业 145、职位类型 134）。
- 新增两只原件（都在 `ui/controls.tsx`，无新依赖）：`DeskFilterField`（触发器，显示「标签：当前值」）与
  `DeskOptionPicker`（面板：← 返回 / 维度名 / 清除 / 搜索框 / 列表 / 完成）。
- **不 portal、不 `fixed`、不加 `z-*`**：它和原生内核视图没有层叠关系；也不进 `overlayLayers`，
  所以 Esc 仍归上层（助手面板/弹窗），不会连它们一起关。
- 搜索：子串、忽略大小写、**不排序**（中文按码点排会成随机名单）；**组字期间不过滤**
  （`isComposing` 为真不更新查询串，专治打「shang」时列表被清空成「没有匹配」）。
- 当前值不在码表里时，触发行下方给一行 amber「当前值「x」不在码表里：这一维不会被发送」，不静默吞。

**门禁**：`pnpm typecheck` → `TYPECHECK_EXIT=0`；`pnpm lint` → `LINT_EXIT=0`（含渲染层三条：控件只出自 `ui/**`、
按钮画法必须具名档位、hover 归归档位函数）；`pnpm format:check` → `FORMAT_EXIT=0`；
`pnpm test` → `TEST_EXIT=0`，**2829 例全过**（platform-boss 196，其中一条改成「可选项里包含 3-5年」——
码表已经是全量 8 档，不再断言整表相等）。

**还没验的（不装已过）**
1. **真站上点选择器**：这一轮只证明「数据入库 + 界面能画 + 门禁绿」，选择器在真站页面上的
   展开/搜索/选中/回填还没有活体读数（要 QA 在真站或仿站上点一遍）。
2. **输入法组字**：`isComposing` 门只有代码层保证，**必须有真实中文输入法的活体验收**（设计 §11 已列）。
3. 多选（行业最多 3、经验/学历/规模/融资/职位类型多选）未启用，`search.multi` 未声明；启用时要写
   「逗号拼 + 逐值查码 + 任一未知整条拒绝」，本轮没做，不假装做了。
