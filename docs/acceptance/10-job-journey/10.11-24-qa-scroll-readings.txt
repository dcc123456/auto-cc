# 10.11-24 Home 滚到底：底栏不压内容 / 状态条四项不相交 / 两档

环境：`d17c1bd` 隔离副本、CDP 10413（QA 段位 + owner 文件）、userData `ud34`；
视口用同一条 CDP 会话里的 `Emulation.setDeviceMetricsOverride`（它只在会话存活期有效，所以「改视口 → 滚动 → 量 rect → 截图」都在一次连接里做完）。

## 1024×720（内容溢出，真滚到底）

| 读数 | 值 |
| --- | --- |
| 视口 | `1024×720` |
| 滚动容器 | `{x:56, y:53, w:968, h:637}`，`scrollHeight 820 / clientHeight 637`，`scrollTop` 由 0 → **184**（= 820-637+1，到底） |
| 底栏 | `{x:0, y:690, w:1024, h:30}` |
| 底栏 × 滚动容器 | 交集面积 **0**（容器下沿 690 = 底栏上沿 690） |
| Home 面板 rect | `{x:76, y:-110, w:928, h:780}`——滚到底后上移出视口，可见部分止于 670，未进底栏 |
| 状态条四项 | 4 项，`运行 / 登录态 / 额度 / 档位`，两两交集 **6 对全 0** |
| 截图 | 顶 `10.11-24-qa-scroll-top-1024.png`（md5 `05b59619…`）／底 `10.11-24-qa-scroll-bottom-1024.png`（md5 `efb71d7b…`），**互异** |

## 1600×1067（内容不溢出，滚到底是无操作）

| 读数 | 值 |
| --- | --- |
| 视口 | `1600×1067` |
| 滚动容器 | **不存在**：`scrollHeight 820 < 可视 964`，整页一屏放得下 |
| 底栏 | `{x:0, y:1037, w:1600, h:30}` |
| Home 面板 rect | `{x:204, y:73, h:780}` → 下沿 853 < 底栏上沿 1037，**不压** |
| 状态条四项 | 两两交集 **6 对全 0** |
| 截图 | 顶／底两张 **md5 相同**（`0916c146…`）——因为这一档没有可滚内容，画面本就不该变 |

## 发现（判据层面的口径问题，P3）

24 原文要求「**两档**各滚到底 … 前后各一张截图且 `md5` 必须不同」。在 1600×1067 上这条**不可满足**：内容只有 820px、可视 964px，滚到底是无操作，前后画面必然相同。
裁定采①：**`md5` 互异只在内容溢出的档位适用**；内容不溢出的档位判「底栏×内容交集 0 + 状态条四项两两不相交 + 底栏不压内容」。原判句保留，本文件按这条执行。

## 结论

- 1024×720：**通过**（底栏不压内容、滚动发生在本屏容器内、状态条四项互不相交、前后截图 md5 互异）。
- 1600×1067：几何三项**通过**（不压、不交），但「滚到底 + md5 互异」在该档是空操作——不是实现缺陷，是判据需要收窄。
